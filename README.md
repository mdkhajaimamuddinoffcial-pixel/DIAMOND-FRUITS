Full-stack fruit shop website.

- Tagline: FIND THE BEST PRICES

Features: customer storefront, ImgBB fruit images, cart, checkout/order form, server-side price and stock verification, admin product/rate/stock management, order management, PostgreSQL migrations and seed data.

Important: GitHub stores the source. GitHub Pages alone cannot run the backend/database. Deploy this full-stack project on a compatible backend host such as Hatchable.
